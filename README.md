# SBTI - 傻乎乎的大人格测试

> 一个娱乐向的梗向人格测试，帮你发现自己的"隐藏人格"

![SBTI](https://img.shields.io/badge/SBTI-Silly%20Big%20Personality%20Test-pink)
![React](https://img.shields.io/badge/React-18.3-blue)
![TypeScript](https://img.shields.io/badge/TypeScript-5.6-blue)
![Tailwind](https://img.shields.io/badge/Tailwind-3.4-cyan)

## 🎯 特色功能

- **27种人格类型** - 从"尤物"到"废物"，涵盖当代年轻人的各种情绪标签
- **31道趣味测试题** - 涵盖生活态度、情感模式、社交行为等多个维度
- **Q版动漫风格图片** - 每种人格都有专属的幽默调侃风格动漫人物图
- **详细人格解读** - 包含人格描述、特质标签和幽默调侃语
- **响应式设计** - 支持手机和电脑，流畅的动画效果

## 🛠️ 本地开发

### 安装依赖

```bash
npm install
# 或
pnpm install
```

### 开发模式

```bash
npm run dev
# 或
pnpm dev
```

### 构建生产版本

```bash
npm run build
# 或
pnpm build
```
